## Retained development evidence

Some older screenshots and review sheets remain because historical source notes link to them. This is deliberate. Their version labels indicate the original development context; they do not imply those older candidates are the current release.

The 49 older render/review PNGs removed from `main` remain retrievable from Git history and can generally be reproduced with the renderer scripts under `Tools/`. All tracked JSON diagnostics and build/validation tools were retained.

For full development history see [Docs/History](../Docs/History/) and [Source/Documentation](../Source/Documentation/).
