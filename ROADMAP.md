# RoosterWorks roadmap

Current build: **0.6** (0.6.0 in version metadata). This is a numbering reset of the complete v0.16.0-dev.3 build, retaining all existing features and development history.

## Planned milestones

| Version | Scope |
|---|---|
| 0.65 | Selectable ring colors on each module and selectable logistics contents |
| 0.7 | 5 m station parts |
| 0.75 | Shorter versions of HAB modules |
| 0.8 | Land Base Station parts — Ground-base modules |
| 0.9 | Adjustable legs or wheels for land bases |
| 0.95 | Large land base concepts |
| 1.0 | Attach modules to science/research tiers |

The requested “5mm station parts” is interpreted as 5 m, extending the current 2.5 m and 3.75 m families. The roadmap identifier 0.95 is retained as requested. Detailed specifications and implementation order within each milestone remain to be decided. The 1.0 milestone covers deliberate research/technology progression; current provisional TechRequired placements remain unchanged.

## 0.65 scope

- **Selectable ring colors on each module** — palette and controls to be decided.
- **Selectable logistics contents** — future storage variants for Food, Water, Oxygen, Ammonia, Waste and other supplies. Current LOG placement remains Station Utility, as clarified; dedicated supply-container placement can be decided with those variants.

These are planned scopes, not implemented features or published releases. The current family retains 23 native models/current catalogue parts with Kerbalism Default, plus two hidden historical reactor IDs for saved-vessel compatibility. Offline validation does not replace live KSP testing.
