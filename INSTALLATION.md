# Installing RoosterWorks Station Modules v0.6.0

**Stable, in-game-tested release for KSP 1.12.5.**

1. Close Kerbal Space Program and back up your saves.
2. Download the **player installation ZIP** from the GitHub release. Do not use a developer-source archive as the player installer.
3. Remove an older `GameData/RoosterWorksStationModules` directory if one exists, to avoid leaving stale files.
4. Extract the archive into your KSP installation directory so that the files appear at:
   `Kerbal Space Program/GameData/RoosterWorksStationModules/Parts/`,
   `.../Models/`, `.../Compatibility/`, and `.../Plugins/`.
5. Launch KSP and confirm the station parts appear in the editor.

### Compatibility

The package includes optional ModuleManager compatibility configurations for Kerbalism and VAB Organizer. Install the corresponding dependencies if you use those integrations. Do not copy `Source`, `Tools`, or `Media` into `GameData`.

### Upgrading

The stable v0.6.0 build retains the full v0.16.0-dev.3 feature set. This version reset is intentional; do not replace it with the older historical v0.6.0 development ZIP.
