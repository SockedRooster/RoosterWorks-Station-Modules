# RoosterWorks Station Modules

**Stable release: v0.6.0** · **Kerbal Space Program 1.12.5** · **MIT License**

RoosterWorks Station Modules adds a coordinated family of station-building parts for KSP, with 2.5 m and 3.75 m modules, station interiors and exteriors, finish options, storage and power variants, and optional compatibility patches.

## Features

- 23 part configurations covering habitation, command, laboratory, cupola, hub, greenhouse, airlock, logistics, power, tubes, elbows, and a 2.5 m-to-3.75 m adapter.
- White and grey exterior finish options, with detailed station textures and model assets.
- Compact reactor options and ElectricCharge/storage balancing.
- Station-focused VAB organization.
- Optional compatibility patches for Kerbalism and VAB Organizer.

## Status

**v0.6.0 is a stable release, verified in-game by the project maintainer.** It retains the complete feature set previously developed under the v0.16.0-dev.3 numbering. The version was intentionally reset to 0.6.0; it is **not** the older historical v0.6.0 development prototype.
