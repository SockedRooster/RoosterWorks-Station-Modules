# RoosterWorks Station Modules v0.7.7

- Show or hide the mission flag on each module in the editor or in flight. Each part remembers its setting. One control operates both ends of the gravity ring.
- Use **Mirror wiring** to move the blue and yellow service lines and their clips to the opposite side of the handrail. Elbow wiring follows the bend, and the six-way hub switches all branches together. **Restore standard wiring** returns the original layout.
- Recommended companions are **RoosterWorks Station Support** for girders, storage hubs and docking couplers, **RoosterWorks Ground Modules** for surface bases, and **RoosterWorks Inflatable Fuel Depot** for orbital propellant storage.

## Installation for KSP 1.12.5

Close KSP and replace GameData/RoosterWorksStationModules with the folder from RoosterWorks-Station-Modules-v0.7.7.zip. Restart KSP.

ModuleManager is required. Community Resource Pack and SystemHeat enable the nuclear industrial parts. Kerbalism and VAB Organizer integrations are optional.
