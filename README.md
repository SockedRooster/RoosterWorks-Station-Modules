# RoosterWorks Station Modules

Procedurally generated, textured space station modules for Kerbal Space Program 1.12.5, with optional Kerbalism life support.

## RW-HAB-250 — Prototype v0.1.0

Our first development part is a **2.5 m, four-crew orbital habitat**. Its geometry and textures are generated by Python; a Blender script recreates the exact model as an editable `.blend` project. The native KSP `.mu` file, compatibility patches, test instructions, and developer sources are included in the approved **RoosterWorks-Station-Modules-v0.1.0-WIP-GitHub-Upload.zip** package.

**Status:** Prototype ready for VAB/flight testing; not yet a released mod. Stock cabin interior used temporarily; original IVA interiors are planned later.

### Importing v0.1.0 source into this repository

The first GitHub commit installs an import workflow. To transfer the prepared model binaries and source files:

1. Download the **RoosterWorks-Station-Modules-v0.1.0-WIP-GitHub-Upload.zip** archive supplied in ChatGPT.
2. Use **Add file → Upload files** on this repository, upload the **single ZIP with its exact filename** directly to `main`, and commit.
3. GitHub Actions will verify the ZIP SHA-256, extract the source and KSP `GameData` files, run static validation, commit the approved files, and remove the temporary ZIP.
4. Once the import succeeds, README will include the full build/run instructions.

There is also a separate **RoosterWorks-Station-Modules-v0.1.0-TEST.zip** for installing in KSP. Do not upload that player ZIP in place of the developer-source archive.
