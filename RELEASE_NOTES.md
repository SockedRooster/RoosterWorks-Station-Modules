# RoosterWorks Station Modules v0.7.5

**Stable release — October 14, 2026 | Kerbal Space Program 1.12.5 | MIT**

v0.7.5 expands the station system with larger parts, selectable configurations and improved editor controls. The author reported successful in-game testing before publishing the stable release.

## Highlights

- New 5 m orbital-station family, including habitation, command, science, greenhouse, airlock, logistics, power and structural parts, plus a 3.75 m-to-5 m adapter.
- Compact habitats and longer crew tubes across the available diameters.
- Selectable White/Grey exterior finishes and ring colors: Original, Steel, White, Charcoal, Blue, Green, Red and Gold.
- Configurable logistics resources, laboratory data/sample capacity tiers and five command archive-size selections.
- Improved ring selection, editor controls, and resource/ElectricCharge balance.
- Existing part IDs and historical reactor choices remain compatible with previously saved craft.
- Kerbalism compatibility patches and optional VAB Organizer integration.

## Install

Download [RoosterWorks-Station-Modules-v0.7.5.zip](https://github.com/SockedRooster/RoosterWorks-Station-Modules/releases/tag/v0.7.5). Back up saved craft, remove the older `GameData/RoosterWorksStationModules` directory and install the complete folder from the release ZIP. See [INSTALLATION.md](INSTALLATION.md).

## Validation

The stable build was tested in-game by the author. The source repository contains a comprehensive offline validation suite and `CHECKSUMS-SHA256.txt` for the shipped game files. Documentation-only cleanup commits made after release do not alter the original v0.7.5 tag or player ZIP.

Detailed earlier development notes, superseded testing warnings and checklists are retained in [Docs/History](Docs/History/).
