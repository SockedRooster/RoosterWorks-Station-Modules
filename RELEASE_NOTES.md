# RoosterWorks Station Modules v0.6.0 — Stable Release

**Status:** Stable · **Tested in-game by the maintainer** · **KSP:** 1.12.5

This release delivers the complete RoosterWorks Station Modules station-building set under the stable `v0.6.0` version number. It carries forward the features and fixes from the former v0.16.0-dev.3 development line; the version-number reset does not remove those features.

## Included

- 23 station part configurations across 2.5 m and 3.75 m families, including crew modules, command, lab, cupola, greenhouse, airlock, logistics, power, tubes, elbows, and adapter.
- White and grey exterior finishes and updated station details.
- Compact reactor and power options, resource/storage balance, and station VAB organization.
- Updated straight-tube model compatibility and corrected elbow artwork UV mapping.
- Optional Kerbalism and VAB Organizer compatibility.

## Installation

Download the player installation ZIP attached to the GitHub release. Extract its `GameData` directory into the KSP installation directory, replacing an older `GameData/RoosterWorksStationModules` folder after backing up saves. See [INSTALLATION.md](INSTALLATION.md).

## Verification

The maintainer confirms that v0.6.0 was tested successfully in KSP. Development-stage warnings and outstanding-test claims in older notes are historical, not the status of this release.
