# Uniformity 04 — visual candidate for v0.7.5-dev.11

Includes the earlier insulation, foil, window and attachment improvements.

- Two standard service lanes at 120 and 240 degrees carry white handrails and blue/yellow cables. Matching-diameter axial interfaces meet at their attachment planes in the default orientation. Adapters transition between diameters and elbows follow the bend.
- Large named module placards and their backings are removed. Small equipment markings and rooster insignia remain.
- The orbital ring's eight habitat sectors, hub and access tubes now use the detailed insulation material and normal map. Native deployment transforms, collider data and controller names are preserved.
- EVA ladder rungs reach and intersect both side rails. The EVA rails reach the module ends.
- Habitat hatch variants use a snug door surround with insulated infill instead of the panoramic window foundation. Their short access ladders remain beside the door, separate from the standard service lanes.

The rotating ring bearing interrupts the handrail; cables pass inside the central sleeve. Cupola service runs terminate below the canopy. Radial hub ports do not define the axial stack alignment. Arbitrarily rotating a module changes lane alignment.

## Install

Back up the existing mod folder, then replace `GameData/RoosterWorksStationModules` with the folder from the Install archive. This is a complete runtime package. Keep the existing external dependencies required by dev.11. No game installation or saves were modified while preparing this package.

## Validation

`Reports/UNIFORMITY_04.json` records native model validation: mesh indices and finite attributes, texture references and normal-map tangents, colliders and gravity transforms, glass positions, color-selector ranges, actual exported interface caps, ladder joins and protected runtime file hashes. Six Blender previews show a default stack, seam, EVA ladder, hatch and both ring poses. Preview lighting differs from KSP.

KSP acceptance remains pending: check mixed stacks, finish and ring colors, hatch switching, cabin lighting, EVA access, and ring deployment/rotation. Runtime performance has not been measured.

## Editable source and rebuild

`Source/Blender/RW_Uniformity04.blend` contains the review scenes. Native `.mu` output is generated by `Tools/build_uniformity.py`; its reproducible input models and original geometry selectors are in `Source/Study04Baseline`. Existing source texture assets and earlier builders are retained.

Use Blender 5.2 background Python with NumPy and Pillow available (`.build-deps` is intentionally omitted from the archive):

```
blender --background --python Tools/build_uniformity.py
python Tools/validate_uniformity.py
blender --background --python Tools/render_uniformity.py
python Tools/package_uniformity.py
```

The builder uses the sibling Attachment-Fix-03 folder if present; otherwise it uses the bundled baseline. Historical notes describe older revisions; this document describes the current candidate.
